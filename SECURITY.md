# Security Policy

## Supported Versions
This project is an **internal agency tool** and is not maintained or supported for external production use. Only the latest commit on the `main` branch is actively maintained.

## Reporting a Vulnerability

If you discover a security vulnerability or sensitive information exposure:

1. **Do NOT open a public GitHub issue, discussion, or pull request.**
2. Report the vulnerability privately to the project maintainers via GitHub's private vulnerability reporting feature:
   - Navigate to the repository on GitHub > **Security** tab > **Advisories** > **Report a vulnerability**.
3. Include:
   - Description of the vulnerability and impact.
   - Minimal steps or proof-of-concept to reproduce.
   - Any recommended remediation.
4. Maintainers will review and deploy patches to `main` promptly.
